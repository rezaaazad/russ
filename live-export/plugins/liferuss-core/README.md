# لایف‌روس — هسته

## آپلود فرم بازرگانی

فرم تأمین کالا تا ۵ فایل و هر فایل تا ۲۰ مگابایت می‌پذیرد. نوع مجاز JPG، PNG، WEBP و PDF است. فایل‌ها بیرون از ریشهٔ وب، با نام تصادفی، ذخیره می‌شوند و اجرای PHP در آن پوشه بسته است.

این افزونه مقدار `upload_max_filesize` و `post_max_size` را تغییر نمی‌دهد. روی سرور:

- `upload_max_filesize` دست‌کم `20M`
- `post_max_size` دست‌کم `105M`

اگر سقف PHP پایین‌تر باشد، فرم همان سقف مؤثر را به کاربر نشان می‌دهد و همان را اعمال می‌کند.
