# لایف روس — درخواست‌ها

افزونهٔ وردپرس برای صندوق ورودی فرم‌ها. قالب، ظاهر فرم‌ها را روی صفحات نگه می‌دارد؛ این افزونه ذخیره، صندوق ادمین، و دسترسی پشتیبانی را مدیریت می‌کند.

## نصب

مخزن قالب لایف روس را در `wp-content/themes/liferuss` قرار دهید. سپس پوشهٔ افزونه را کپی یا لینک کنید:

```bash
ln -s /path/to/russ/plugins/liferuss-leads wp-content/plugins/liferuss-leads
```

یا کل `plugins/liferuss-leads/` را به `wp-content/plugins/liferuss-leads/` کپی کنید.

در **افزونه‌ها**، «لایف روس — درخواست‌ها» را فعال کنید. با فعال‌سازی، نقش **پشتیبانی لایف روس** ساخته می‌شود و نوع نوشتهٔ `liferuss_lead` (همان صندوق قبلی قالب) توسط افزونه ثبت می‌شود.

اگر افزونه خاموش باشد، قالب به هندلر داخلی خودش برمی‌گردد تا فرم‌ها از کار نیفتند.

## نوع فرم‌ها

| اسلاگ | استفاده در قالب |
|---|---|
| `consult` | فرم مشاوره تحصیل (`template-parts/consult-form.php`) |
| `freight` | لندینگ باربری |
| `trade` | لندینگ تجارت |
| `contact` | صفحه تماس (`template-parts/contact-form.php`) |

نوع جدید با فیلتر `liferuss_leads_form_types` اضافه می‌شود. فیلدهای اضافه را با `liferuss_leads_extra_fields` بفرستید.

فرم‌ها همان `action=liferuss_consult`، nonce `liferuss_consult`، و honeypot `liferuss_company` را نگه می‌دارند.

## دسترسی پشتیبانی

1. کاربر جدید بسازید و نقش **پشتیبانی لایف روس** بدهید.
2. در **درخواست‌ها → تنظیمات فرم‌ها** (یا ویرایش کاربر) نوع فرم‌های مجاز را علامت بزنید.
3. آن کاربر فقط همان نوع‌ها را در صندوق می‌بیند. مدیران همه را می‌بینند و می‌توانند مسئول پیگیری تعیین کنند.

وضعیت هر درخواست: جدید / در حال پیگیری / انجام شد.

## امنیت

Nonce، honeypot، sanitization، و آپلود امن JPG/PNG/PDF تا ۱۰ مگابایت مثل فرم‌های لندینگ قالب.
